## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/imdurgeshhh/Portfolio-anatomical.git

# Navigate into the project directory
cd Portfolio-anatomical

# Install dependencies
npm install

# Start the development server
npm run dev
```

The site will be running at `http://localhost:5173` (or the port shown in your terminal).

### Build for Production

```bash
npm run build
```
